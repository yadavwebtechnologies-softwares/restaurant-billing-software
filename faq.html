Website Development & Software FAQs

GENERAL

About the services

What services does Yadav Web Technologies provide?

Services include website development, business management software, web tools, WhatsApp automation, membership and certification management, Firebase integration and Cloudflare configuration.

Can I request a custom website or software?

Yes. Share the problem you want to solve, the features you need and your intended users. The requirements can then be reviewed to determine an appropriate project scope.

Do you work on existing projects?

Share the current project, its technology stack, required changes and access constraints for an initial review. Whether the work can be undertaken depends on the project's requirements.

PRICING & QUOTATIONS

Project costs

How much does a website cost?

The cost depends on the number of pages, required features, design complexity and technical requirements. Share your needs to discuss a suitable quotation.

How is custom software priced?

Custom software pricing depends on the required modules, workflows, integrations, testing and deployment scope. The estimate should be based on the agreed requirements.

Are hosting and domain costs included?

This depends on the project agreement. Domain registration, hosting, third-party APIs and other external services may involve separate costs that should be clarified before work begins.

DEVELOPMENT

Project planning and delivery

How long will my project take?

The timeline depends on the project scope, complexity, required integrations and review process. An estimated timeline can be discussed after the requirements are understood.

Can I request changes during development?

Yes, changes can be discussed. New requirements may affect the agreed scope, cost or timeline, so their impact should be reviewed before implementation.

Will my website work on mobile devices?

Responsive behavior can be included in the agreed scope. The layout should be reviewed across appropriate screen sizes before delivery.

HOSTING & TECHNOLOGY

Deployment and integrations

Can a website be hosted on GitHub Pages?

GitHub Pages can host supported static websites. Projects requiring secure server-side processing, backend logic or database operations need an appropriate additional service.

Can Firebase be integrated into a project?

Firebase integration can be considered for suitable applications. The required services, authentication, database structure and security rules must match the project's architecture.

Can WhatsApp automation be implemented?

Suitable automation workflows may use supported WhatsApp integrations and APIs. Implementation depends on access, permissions, platform policies and the requested functionality.

SUPPORT & MAINTENANCE

After project delivery

Is maintenance included?

Maintenance depends on the agreed project scope and service arrangement. Any included support, duration and additional charges should be confirmed before delivery.

Will I receive the project files?

Source files, repository access, documentation and handover arrangements should be specified in the project agreement before work begins.
